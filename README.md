# UTSL服务器管理器

开发团队：**流光工作室** · 署名：**流光-Pigeon-X**

独立的本地 Windows / Avalonia 多服管理器。界面参考团队 CNS-Team/PGame-TSManager，地图工坊直接嵌入 CNS-Team/UTSL-MapStudio 同一窗口，生成器通过锁定 git 子模块独立维护。

## 程序目录

```text
Pigeon-UTSLManager/
  UTSl-Manager.exe
  Plugins/            总插件库，元数据 / SHA256，不执行插件
  Servers/            每服完整独立包，或现有目录的登记引用；按 0. / 1. / 2. 递增编号
  Maps/               地图工坊的批次输出、三联世界长图
  Backups/            插件 / 配置修改前备份和清单
  Data/               服务器名册、每服日志、操作审计
  App/                UI / 持久后台 / 地图引擎 / licenses
```

## 使用

双击根 EXE。程序和数据都固定在此根目录；空名册首次启动不会自动导入、接管或启动任何服务器。复制导入完整 UTSL 服务端包时只复制到 Servers 的新目录，不修改原目录、不接管原进程、不自动启动。也可选择“登记现有目录”原地管理：只保存引用，不复制或启动，已经运行的同路径进程显示为外部运行。各包仍使用自身配置；复制导入前先保证源包停止或是稳定离线快照。多个包必须配置不同的监听端口。

左侧服务器按目录数字编号排序，例如 `0.PigeonGame`（流光城）在 `1.PigeonLive`（生存服）前。“全部启动”和后台自动启动共用一个队列：前一服配置的全部世界均 running 且每个世界 status 正确后，才创建下一服进程。加载时后台和控制台仍可操作；失败、进程提前退出或超时会暂停队列，后续服务器不启动，也不自动强杀或重试。默认每服等待上限600秒，可通过名册 `StartupTimeoutSeconds` 设置1–3600秒。需要服务端 `config/config.json` 的 launcher.autoStartServers 和 `config/TShockAPI/config.json` 的本机 REST 端口、令牌；HTTP 200 的“世界不存在”响应不视为就绪。

选择左侧一台服务器后，上方 `1 / 2 / 3` 切换这台 UTSL 的世界控制台，“显示三个”可并排显示三个世界；不再使用跨服务器双控制台。三联世界按西、中、东显示，命令只进入所选精确世界名的输入队列，不广播、不用日志标签猜世界。需要配套核心的本地世界控制台接口：每次启动产生新的随机命名管道，仅当前 Windows 用户访问，进程代际变化拒绝旧接口；核心以 unified 模式运行，不另弹世界窗口。宿主页保留完整启动输出及协调器控制台，旧核心接口不可用时明确退回宿主页。

标题栏左侧是 macOS 三色按钮，右侧提供全屏、最小化、最大化/还原和关闭；双击空白标题栏最大化，Esc 可退出全屏。宿主终端使用真实 Windows ConPTY，保留控制台 API / 中文 / ANSI 色彩；每服拥有独立输入输出。关闭 UI 不关闭后台，不停止服务器。重新打开会连回同一后台；后台意外崩溃不保证控制台继续存活，不宣称具有 Windows 服务级容灾。

右上工具栏提供单服启停、重启，以及全部启动、全部停止。停止先核验并保存每个仍在运行的世界，只有 REST 明确返回 `World saved` 才继续；已停止的世界记为 `NO_RUNNING_WORLD`。随后只发送一次 `/off`，等20秒；若所属宿主仍残留，再核对 PID / 完整路径 / 创建时间，仅结束这个单进程并等待退出，不树杀、不按名称杀。保存失败保留进程并显示失败，不冒称停止成功。全部停止会先取消启动队列，使尚未启动的服务器保持停止，再逐服保存、停止；外部运行的进程不会被接管或结束。

控制台读取和 ANSI/VT 解析都由后台采集器完成。界面只接收最近一帧不可变内容，以有界频率更新可见窗口，未变化的文字复用绘制缓存；隐藏控制台和最小化时暂停采集。每世界保留有界回放，界面不会逐日志向 UI 线程堆积刷新任务，切换页签也会丢弃旧选择的异步结果。

“启动设置”可编辑本服名册参数，也可显式开启后台启动时自动启动此服，默认关闭；“原生配置”编辑 config/config.json，仅停止时可保存，先备份。预检端口字段只是检查，不能替代服务端原生端口配置。

总插件库可导入托管 DLL，查看版本 / 长度 / SHA；选择目标服和文件后，只有目标服已停止才会备份并原子复制到 Plugins。复制成功不代表已加载或插件兼容；不会自动复制所有库、热载或启动。

地图工坊保留生成器的完整模式、特殊种子、基础环境补全和实时图格预览，输出在根 Maps。只使用有 COMPLETE.json 的成功批次。仅生成 / 预览，不自动替换现有服世界。

## 开发

需要 Windows 10 1809+ / Windows 11、PowerShell 7、.NET 10 SDK 与 .NET 9 运行时。首次 clone 要 `git submodule update --init --recursive`。UI / 后台可独立构建；完整地图依赖遵循子模块 docs/DEPENDENCIES.md 的输入 SHA 锁，不随本仓库分发引擎二进制。

```powershell
./scripts/Build.ps1
./scripts/Package.ps1 -Destination <新的程序目录> -MapDependencyRoot <已有合法地图生成器依赖根>
```

发布包创建前必须确认目标目录不存在。MapDependencyRoot 仅指向本机已有、与 MapStudio 锁定清单 SHA 完全一致的 engine/ 与 lib/TEdit/ 输入；不通过本仓库或 CI 公开分发游戏引擎二进制。未连接生产的测试只证明本地组件范围。后台进程 Running 不等于世界可玩、准入成功或真实玩家 E2E；导入包必须自行核对运行版本和端口。本管理器没有内置生产地址或凭据。
