# UTSL服务器管理器

开发团队：**流光工作室** · 署名：**流光-Pigeon-X**

独立的本地 Windows / Avalonia 多服管理器。界面参考团队 CNS-Team/PGame-TSManager，地图工坊直接嵌入 CNS-Team/UTSL-MapStudio 同一窗口，生成器通过锁定 git 子模块独立维护。

## 程序目录

```text
Pigeon-UTSLManager/
  UTSl-Manager.exe
  plugins/            总插件库，元数据 / SHA256，不执行插件
  servers/            每服完整独立包，或现有目录的登记引用
  maps/               地图工坊的批次输出、三联世界长图
  backups/            插件 / 配置修改前备份和清单
  data/               服务器名册、每服日志、操作审计
  app/                UI / 持久后台 / 地图引擎 / licenses
```

## 使用

双击根 EXE。程序和数据都固定在此根目录；空名册首次启动不会自动导入、接管或启动任何服务器。复制导入完整 UTSL 服务端包时只复制到 servers 的新目录，不修改原目录、不接管原进程、不自动启动。也可选择“登记现有目录”原地管理：只保存引用，不复制或启动，已经运行的同路径进程显示为外部运行。各包仍使用自身配置；复制导入前先保证源包停止或是稳定离线快照。多个包必须配置不同的监听端口。

选择服务器后启动、查看控制台、发送命令。支持双控制台并排对照。标题栏左侧是 macOS 三色按钮，右侧提供全屏、最小化、最大化/还原和关闭；双击空白标题栏最大化，Esc 可退出全屏。终端使用真实 Windows ConPTY，保留控制台 API / 中文 / ANSI 色彩；每服拥有独立输入输出。关闭 UI 不关闭后台，不停止服务器。重新打开会连回同一后台；后台意外崩溃不保证控制台继续存活，不宣称具有 Windows 服务级容灾。

正常停止仅发送一次 `/off`，等 20 秒。超时会明确提示，不自动重试或强杀；用户另行确认后才允许对精确 PID / 完整路径 / 创建时间一致的单进程强停，不树杀、不按名杀。外部运行的同路径进程只标“外部运行”，不写其控制台、不自动接管。

“启动设置”可编辑本服名册参数，也可显式开启后台启动时自动启动此服，默认关闭；“原生配置”编辑 config/config.json，仅停止时可保存，先备份。预检端口字段只是检查，不能替代服务端原生端口配置。

总插件库可导入托管 DLL，查看版本 / 长度 / SHA；选择目标服和文件后，只有目标服已停止才会备份并原子复制到 plugins。复制成功不代表已加载或插件兼容；不会自动复制所有库、热载或启动。

地图工坊保留生成器的完整模式、特殊种子、基础环境补全和实时图格预览，输出在根 maps。只使用有 COMPLETE.json 的成功批次。仅生成 / 预览，不自动替换现有服世界。

## 开发

需要 Windows 10 1809+ / Windows 11、PowerShell 7、.NET 10 SDK 与 .NET 9 运行时。首次 clone 要 `git submodule update --init --recursive`。UI / 后台可独立构建；完整地图依赖遵循子模块 docs/DEPENDENCIES.md 的输入 SHA 锁，不随本仓库分发引擎二进制。

```powershell
./scripts/Build.ps1
./scripts/Package.ps1 -Destination <新的程序目录> -MapDependencyRoot <已有合法地图生成器依赖根>
```

发布包创建前必须确认目标目录不存在。MapDependencyRoot 仅指向本机已有、与 MapStudio 锁定清单 SHA 完全一致的 engine/ 与 lib/TEdit/ 输入；不通过本仓库或 CI 公开分发游戏引擎二进制。未连接生产的测试只证明本地组件范围。后台进程 Running 不等于世界可玩、准入成功或真实玩家 E2E；导入包必须自行核对运行版本和端口。本管理器没有内置生产地址或凭据。
