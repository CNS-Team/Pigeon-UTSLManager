# UTSL Manager 首版本地实现

1. 建立独立源码根、目录和进程协议；不修改 TSM 或生产。
2. 后台宿主使用 ConPTY 和每进程精确身份，关闭 UI 不停止服务端。
3. 多服控制台、插件库、配置入口与 MapStudio 同窗口工作区。
4. 隔离包 / 真实 UTSL 本地验证、UI 截图、根 EXE 交付；任何未验证项明列。

目录：UTSl-Manager.exe、Plugins、Servers、Maps、App、Backups、Data。复制导入服务端包只复制到新目录；登记现有目录只写引用，均不自动接管已有进程。插件更新只允许停止的目标服；按文件 SHA 备份后替换，不热载，不宣称所有插件最新。自动启动默认关闭，只有显式保存 AutoStart=true 的名册项目才在后台取得单实例锁后启动一次。

安全边界：不按进程名杀、不树杀、不自动强杀、不自动回退、不自动重启、不把宿主进程存活等同世界可玩。常规停止发送一次 /off，超时保留现场。强停必须由用户单独确认精确 PID / 路径 / 创建时间。

UI 参考 CNS-Team/PGame-TSManager；地图功能来源 CNS-Team/UTSL-MapStudio，以锁定 git 子模块维护，非另复制一套生成源码。
